# Tanzania prospect presentation concepts

These are independent, unofficial presentation concepts created by Korvia Studio from public information. They are not client websites and do not imply endorsement.

Use `index.html?for=SLUG`. Available slugs are: `cheso`, `patandi`, `tgga`, `youthpeacemakers`, `ocode`, `fff`, `ennovate`, `hsh`, `grace`, `palace`, `bestway`, `alhulbait`, `springofhope`, `almaktoum`, `minja`, `efco`, and `acacia`.

`round-two.html` is the internal review dashboard for the additional 30 Tanzania and 30 non-church Uganda institutional concepts defined in `institutional-prospects.js`.

Illustrative Unsplash photographs must be replaced by organization-approved images before any production deployment. The concepts use `noindex,nofollow` and display an explicit unofficial-concept notice.
