The consolidation challenge

Ten existing sites. One coherent architecture.

VIED's economic-development work is currently spread across multiple program websites, each with its own navigation, templates and content patterns.

A unified WordPress platform would bring those properties together under a shared design system: consistent wayfinding, reusable components, common templates and a single administrative workflow. The result is a site that feels like one institute — not a collection of separate microsites — while still giving each program room to communicate its own services and audiences.

Accessibility & standards

Built to be usable by everyone, on every device.

The proposed site targets WCAG 2.1 AA compliance as a baseline, with attention to keyboard navigation, color contrast, screen-reader structure, readable type and responsive breakpoints.

It is also designed to be search-friendly and mobile-responsive from the start, so community members, business owners, students and partners can find what they need whether they are on a phone, tablet or desktop.

  • WCAG 2.1 AA color contrast and focus states
  • Semantic HTML and logical heading hierarchy
  • Mobile-first, responsive layouts
  • Search-optimized URL structure and metadata
Content & migration

From scattered pages to a unified publishing system.

A consolidation project is as much about content architecture as it is about design. The build would standardize how information is organized, published and maintained.

01

Unified navigation

A single information architecture that helps visitors move between programs without relearning the menu on every subsite.

02

Common templates

Standard page layouts for programs, events, resources, news and landing pages — reducing design debt and improving consistency.

03

Reusable components

Blocks for calls to action, program cards, event listings, partner logos and contact panels that editors can assemble without custom coding.

04

Editor training

Documentation and hands-on guidance so VIED staff can manage content confidently after launch.

Approach

From audit to launch — and beyond.

A phased delivery model keeps the project organized, stakeholder input structured and risk low as the new site takes shape.

Discover

Audit

Review existing sites, content, analytics and stakeholder needs to establish the consolidation scope.

Structure

Sitemap

Define a unified information architecture and URL strategy that serves all programs.

Design

Design system

Create accessible visual standards, component library and page templates in WordPress.

Engineer

Build

Develop the theme, components and integrations on a staging environment.

Migrate

Content migration

Move, restructure and clean content so it fits the new templates and navigation.

Validate

Testing

Accessibility, performance, cross-browser and mobile testing before go-live.

Release

Launch

Deploy the new site, configure redirects and monitor for issues.

Sustain

Training

Train the VIED team and hand off documentation for ongoing content management.
